Model key

This app treats each entry as an activation episode:

E = (A, V, C, P, R, Q, M, L)

A = charge/intensity, V = speed/onset, C = understandability/coherence, P = movement/passage, R = return/recurrence, Q = quadrad recruitment, M = movement shape, L = optional emotion label.

About this pilot

This is a minimal EVF data-collection prototype. It does not diagnose emotions. It records movement signatures before emotion labels.

movement signature → possible regime → optional emotion label

The first research question is simple: can people describe emotional episodes by movement shape before naming the emotion?

Data is stored only in this browser’s local storage unless you export it. Clearing your browser storage may erase entries.
