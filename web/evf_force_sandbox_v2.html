EVF Force Sandbox v2

Stronger, more obvious mappings. Each slider now drives one dominant visual variable so the force differences are easier to read.

Primary mappings
damping = global compression
diffusion = spread radius
drift = sideways pull
attractor = local sink depth
noise = jitter density
rhythm = pulse amplitude
This version exaggerates each force. The goal is legibility first, finesse later. If a slider still feels ambiguous, its mapping should be simplified further rather than decorated.
